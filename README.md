# Sales-Performance-Dashboard-Power-BI-Power-Query-DAX
Sales Performance Dashboard | Power BI, Power Query, DAX
Built an interactive sales dashboard in Power BI from a messy raw sales dataset. I cleaned and transformed the data in Power Query, then created DAX measures for Total Sales, Total Revenue, Total Quantity, and Average Order Value. The dashboard includes revenue by region, sales by category, and a quarterly revenue trend, along with a written insights panel.

Key findings:

Revenue declined about 50% between January and October 2025.
North was the top region, contributing about 36.5% of total revenue, while West was the lowest.
Furniture was the top-selling category, followed by Electronics.
